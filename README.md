# Faby RF Beauty & Spa

Sitio web oficial preparado para GitHub + Netlify.

## Estructura
- `index.html`: página pública.
- `assets/`: imágenes y videos.
- `content/site.json`: contenido editable del sitio.
- `admin/`: panel Decap CMS.
- `netlify.toml`: configuración de Netlify.

## Redes sociales
La sección **Síguenos** incluye iconos clicables para Instagram, TikTok, Facebook y WhatsApp.

## Panel administrador
La ruta es `/admin/`. Para que el inicio de sesión funcione, falta completar la autenticación GitHub/Decap después de conectar este repositorio a Netlify.
